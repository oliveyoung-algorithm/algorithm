## 파일명 규칙

- **날짜 기준**: `YYMMDD` 형식 (ex. `251229.cpp`, `260101.cpp`)
- 본인 이름 폴더 내에 주차별로 정리

## 커밋 규칙

```
[사이트] 문제번호 문제이름 (난이도)
```

예시:

- `[PGS] 12345 타겟 넘버 (Lv.2)`
- `[BOJ] 2557 Hello World (B5)`
- `[SWEA] 1234 문제이름 (D3)`
- `[LEET] 1234 문제이름 (Medium)`

## 자동 커밋 체크 & 벌금 시스템 (GitHub Actions)


- GitHub Actions 워크플로우 `Check Daily Commits`가 **매일 12:00 (KST)**에 실행됩니다.
- 전날(평일 기준) 각 **참여자의 커밋 여부**를 확인합니다.
  - 커밋이 없으면 자동으로 Issue를 생성합니다.
  - `README.md`의 **회식비 누적 금액**에 **5,000원**이 자동으로 추가됩니다.
- 참여자 전체(기존 인원 + 새로 합류한 **이용훈, 최어진**)가 모두 자동 체크 대상입니다.
